# v0.10.0-preview.1：用 npm/npx 安装

本版提供命令行安装预览。无需提前下载安装包；已有环境直接复用，缺少时准备 Jev、uv、Python 和锁定依赖。自动选题、持续追问、草稿恢复、完整问答和计时继续使用原研究核心。

## 第一次使用

1. 使用 Windows 10/11 x64，先从 [Node.js 官网](https://nodejs.org/)安装 LTS 版，再重新打开终端。
2. 复制整条命令到终端，按回车：

```powershell
npx.cmd --yes "https://github.com/qiluoli-usc/copilot-discussion/releases/download/v0.10.0-preview.1/copilot-discussion-0.10.0-preview.1.tgz" setup
```

3. 等待完成，用 Chrome 打开终端给出的“开始使用.html”。选择自己的 AI 软件，按编号步骤连接。
4. 开启 Chrome 远程调试、手动批准 Allow、登录 Microsoft 365 Copilot，然后按说明发送检查和研究提示词。

完整步骤见 [第一次安装](../installation.md)，软件内操作见 [七个宿主说明](../host-setup.md)。首次下载可能需要几分钟；出现下载或依赖准备提示时请等待同一条命令完成。

## 这版可以做什么

- `setup`：检测并复用环境，将运行程序保存到固定目录，准备宿主 MCP 和两个完整技能。
- `doctor` / `doctor --browser`：分别检查本地文件和依赖、Chrome 连接。
- `hosts` / `guide`：查看宿主检测结果，找到本机步骤说明。
- `update`：查询本仓库版本，核对 SHA256 后安装新包，保留研究和旧版本。
- `repair`：补回缺失文件和连接，修复环境；保留人工修改过的宿主配置和技能。
- `uninstall`：移除登记的连接和当前版本文件，保留研究、共享依赖、备份及人工修改。

将安装命令最后的 `setup` 替换成对应命令即可；也可按安装说明全局安装，使用短命令。

七类宿主：Codex、Claude Code、WorkBuddy、QwenWork、DSH、GitHub Copilot CLI、VS Code GitHub Copilot。QwenWork 仍需一次界面导入；DSH 需加载实际启动配置。宿主自身信任、浏览器 Allow 和账号登录需要用户完成。

## 验证与范围

86 项 Node 测试、11 项 Python 测试通过；官方 MCP SDK 完成 11 个工具发现及关键调用验证。隔离环境验证了 npm 安装、npx 网址入口、环境复用、全新 Jev 和托管 Python 准备、重复配置、修复、卸载及记录保留。测试没有打开浏览器或调用模型。详细口径见 [验证记录](../validation/v0.10.0-preview.1.md)。

这验证了七宿主的配置与技能文件流程，尚未逐一运行七个客户端登录联调。当前 Native 执行层适用于 Windows 本机 Chrome；其他系统、架构、WSL、容器和云端 Agent 未获得完整运行验证。

此预览通过 GitHub 分发标准 npm 包，**尚未发布到 npm 公共仓库**。请使用完整 GitHub 地址。旧 EXE 仍保留在原有 Release，本版不需要下载它。
