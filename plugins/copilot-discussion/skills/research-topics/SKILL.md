# 公开资料研究选题

由当前宿主 Agent 提出、比较和筛选主题；宿主搜索工具提供证据。无需额外模型 API、付费论文插件或私人资料。

## 搜索与选题

用户已授权自动选题并讨论时，先按主讨论技能的 `references/mcp-workflow.md` 调用 `discussion_init`，再搜索，以便计入真实准备耗时。候选、阅读来源与选择理由通过 `discussion_select` 一次保存。没有 MCP 工具时用该技能的 `references/research-workflow.md` 和 `ResearchRun.create/select`；两者使用同一记录格式。只要求推荐主题时直接交付候选，无需打开浏览器讨论。

1. 结合用户兴趣及当前对话推断范围；用户选择“通用研究主题”时给出不同方向的 3–5 个候选，不需要再要求用户先指定具体主题。
2. 用宿主已有网页搜索寻找论文、官方报告或公开数据，再实际打开原文。每个候选至少一项已读来源。优先免费可访问资料；不要要求安装付费服务才能继续。Scite 等可选服务仅在用户另行要求且已确认连接时使用。
3. 选能形成争议、反例、实验或决策的问题，避免只有名词介绍的宽泛主题。将来源已证实的事实与模型提出的假设分开，不能把标题、摘要或引用次数当成结论。
4. 写明发布日期或更新时间。网页最近抓取不等于内容最近更新；停止维护的榜单不能作为实时排名。论文的结论只适用于其模型、数据和任务条件。
5. 不读取其他浏览器历史、聊天或私有工作区。用户另行指定私人资料时再选择适用的连接器，并限定检索范围。

## 输出

每个候选包含：

- 具体研究问题及其讨论价值；
- 已读原始来源链接、日期、证据局限；
- 一个可证伪的初步假设，以及可能推翻它的证据；
- 可直接发给 Copilot 的首问，包含背景、边界、证据要求和预期成果；
- 建议停止条件，例如产出比较表、验证方案或决策树；
- 推荐顺序及简要依据，说明这是当前模型的判断。

默认先提供选题清单。用户已经授权“自动选题后直接讨论”时，自主选择最匹配目标、证据可得且可在约定轮数内推进的主题，随后使用同一插件的 `copilot-discussion` 技能开始讨论。不要预先写死所有追问；下一问仍应根据 Copilot 的实际回答产生。

独立选题需要保存时写入工作项目的 `output/research-topics/`，使用唯一文件名。选题后继续讨论时，候选直接归入本次 `output/research-runs/<run-id>/topics.json`；每个来源保存标题、版本日期、实际阅读时间、免费可访问标记与证据局限。来源链接随首问传递，不将模型提出的假设标记为论文结论。
